# ผลสลากกินแบ่งรัฐบาล 16 ม.ค. 2538 – 1 พ.ย. 2569

ไฟล์หลัก: [`data/thai_lottery.csv`](data/thai_lottery.csv) (UTF-8 with BOM เปิดใน Excel ได้ภาษาไทยไม่เพี้ยน) — 761 งวด, 1 แถวต่องวด

ไฟล์ในโฟลเดอร์ `data/` มีชื่อคงที่ เว็บไซต์เรียกใช้ได้จาก
`https://raw.githubusercontent.com/<owner>/<repo>/main/data/thai_lottery.csv`

## คอลัมน์

| คอลัมน์ | ความหมาย |
|---|---|
| `draw_date` | วันที่งวด (ค.ศ., YYYY-MM-DD) |
| `draw_date_th` | วันที่งวดแบบไทย (พ.ศ.) |
| `source` | แหล่งข้อมูลของแถวนั้น |
| `first` | รางวัลที่ 1 |
| `first_special` | รางวัลที่ 1 พิเศษ (มีข้อมูล 1 มิ.ย. 2547 – 16 พ.ค. 2554, 166 งวด) เช่น `กลุ่ม1:ชุด10\|กลุ่ม2:ชุด66` = เลขรางวัลที่ 1 ชุดที่ 10 และชุดที่ 66; บางงวดเว็บต้นทางไม่ระบุเลขชุดจึงเว้นว่าง |
| `near_first` | รางวัลข้างเคียงรางวัลที่ 1 |
| `second` … `fifth` | รางวัลที่ 2–5 |
| `front3` | เลขหน้า 3 ตัว (เริ่มมีตั้งแต่ 1 ก.ย. 2558; ก่อนหน้านั้นเว้นว่าง) |
| `back3` | เลขท้าย 3 ตัว (4 หมายเลขก่อน 1 ก.ย. 2558, หลังจากนั้น 2 หมายเลข) |
| `last2` | เลขท้าย 2 ตัว |
| `prizes_2_to_5_available` | `no` = แหล่งข้อมูลไม่มีรางวัลข้างเคียงและรางวัลที่ 2–5 ของงวดนั้น |
| `reconciliation_notes` | งวด 2550–2559 ที่แหล่งข้อมูลไม่ตรงกัน: บอกว่าใช้ค่าจากแหล่งใด (ดู `reconciliation_log.txt`) |
| `source_url` | หน้าเว็บ/API ที่ใช้ |

รางวัลที่มีหลายหมายเลขคั่นด้วย `|` และเรียงจากน้อยไปมาก (ลำดับการจับไม่ได้เก็บไว้ เพราะเว็บเก่าไม่มีข้อมูลนี้)

## แหล่งข้อมูลตามช่วงเวลา

| ช่วง | แหล่ง | หมายเหตุ |
|---|---|---|
| 16 พ.ย. 2559 – 1 พ.ย. 2569 (237 งวด) | API สำนักงานสลากฯ `glo.or.th/api` เท่านั้น | ไม่แก้ไขค่าใด ๆ |
| 2550 – 1 พ.ย. 2559 | lotto.join.in.th + news.sanook.com | ถ้าสองเว็บตรงกันใช้ได้เลย ถ้าไม่ตรงใช้เสียงข้างมากร่วมกับ GitHub สองชุด |
| 2538 – 2549 | lotto.join.in.th | ไม่มีแหล่งที่สองที่ดึงได้มาตรวจทาน |

- **ไม่มีรางวัลข้างเคียงและรางวัลที่ 2–5:** 126 งวด ตั้งแต่ 16 ม.ค. 2538 ถึง 16 ก.ค. 2543 ไม่มีแหล่งไหนที่อนุญาตให้ดึงข้อมูลมีส่วนนี้ (myhora.com บล็อกการดึงอัตโนมัติ จึงไม่ได้ใช้)
- **งวดที่ join.in.th ว่างเปล่า:** 1 พ.ย. 2553, 1 มี.ค. 2557, 16 ก.ย. 2557 ใช้ Sanook แทน
- **งวด 16 ม.ค. 2549:** join.in.th ลิงก์ไว้ผิดเป็น "1 ม.ค. 2549" จึงใช้หน้าที่ถูกต้องแทน
- **งวด 16 ม.ค. 2540:** หน้ามีอยู่แต่ไม่ได้ลิงก์จากหน้ารายปี จึงเพิ่มเข้ามาเอง
- **งวด 1 เม.ย. 2563:** เลื่อนไปออกรางวัลจริงวันที่ 16 พ.ค. 2563 (COVID-19) แต่ API ของกองสลากฯ ใช้วันที่งวดเดิม
- **งวดสิ้นปี 2567:** ไม่มีงวด 30 ธ.ค. 2567 เพราะเลื่อนไปออก 2 ม.ค. 2568

## การตรวจทานช่วง 2550–2559 (125 จุด ใน 87 งวด; รายละเอียดใน `reconciliation_log.txt`)

- งวด 1 ธ.ค. 2550 และ 1 มี.ค. 2554 Sanook ไม่มีหน้า จึงใช้ join.in.th อย่างเดียว (ไม่ได้ตรวจทาน)

- ส่วนใหญ่เป็นตัวเลขพิมพ์ผิดหนึ่งหลักหรือสลับหลัก หรือเลขหายบางตัวใน join.in.th แล้ว Sanook กับ vicha ตรงกัน
- 5 งวด (16 ต.ค. – 30 ธ.ค. 2550) ทุกแหล่งมีรางวัลข้างเคียงผิดเหมือนกัน (เช่น `103298`) จึงคำนวณจากรางวัลที่ 1 ±1 ตามนิยามของรางวัล
- 6 จุดมีแหล่งเดียวที่ครบ (`vicha` 4 จุด, `sanook` 2 จุด) ความมั่นใจต่ำกว่าจุดอื่น

## อัปเดตอัตโนมัติ

GitHub Actions ([`.github/workflows/update.yml`](.github/workflows/update.yml)) รันทุกวันเวลา 17:00 และ 21:00 น. (เวลาไทย)
เรียก [`scripts/update_from_glo.py`](scripts/update_from_glo.py) ซึ่งดึงงวดใหม่จาก API ของกองสลากฯ เท่านั้น
ต่อท้าย `data/thai_lottery.csv` และเก็บ JSON ดิบใน `raw/glo/` แล้ว commit ให้เอง
งวดที่ผลยังไม่ครบทุกรางวัลจะถูกข้ามไปก่อนแล้วลองใหม่รอบถัดไป; สั่งรันเองได้จากแท็บ Actions → Update lottery results → Run workflow

## ไฟล์อื่น

- `data/reconciliation_log.txt` — ทุกจุดที่แหล่งข้อมูลไม่ตรงกันและค่าที่เลือก
- `data/github_crosscheck.txt` — ผลเทียบ CSV นี้กับ GitHub ทั้งสองชุดทีละงวด
- `data/validation_issues.txt` — ผลตรวจจำนวนหมายเลขของทุกรางวัลทุกงวด (ว่างเปล่า = ผ่านทั้งหมด)
- `raw/glo/` — JSON ดิบจาก API ของกองสลากฯ ทีละงวด

หน้าเว็บที่ดาวน์โหลดจาก lotto.join.in.th และ news.sanook.com ไม่ได้เก็บไว้ใน repo นี้ (เป็นหน้าเว็บของเจ้าของเว็บนั้น); ใช้สคริปต์ด้านล่างดาวน์โหลดใหม่ได้

## สร้างใหม่

```bash
python scripts/fetch_glo.py raw/glo
python scripts/fetch_join.py raw/join
python scripts/fetch_sanook.py raw
python scripts/build_csv.py raw data/thai_lottery.csv data/validation_issues.txt data/reconciliation_log.txt
python scripts/crosscheck.py data/thai_lottery.csv raw/github data/github_crosscheck.txt
```
